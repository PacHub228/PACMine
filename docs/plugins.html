Lua-плагины

Выделенный сервер можно расширять скриптами на Lua: NPC, автоответчики, мини-игры, кастомные команды — всё через один глобальный стол pacmine.

Как включить

  1. В server.properties поставь plugins=true
  2. Запусти сервер — он создаст папку plugins/ с этой же документацией внутри (README.txt)
  3. Положи в неё .lua-файлы — они грузятся по алфавиту при старте
Только исходный текст Lua. Скомпилированный байткод .luac отклоняется — проверка идёт не по расширению файла, а по сигнатуре \x1bLua в начале, так что просто переименовать не получится.

Ошибка в одном плагине не роняет сервер — она просто пишется в лог, и сервер работает дальше.

NPC

NPC выглядят для клиентов как обычные игроки — с телом и ником над головой.

ФункцияОписание
pacmine.spawn_npc(name, x, y, z)создать NPC, вернёт его id
pacmine.move_npc(id, x, y, z [, yaw])переместить NPC, вернёт true/false
pacmine.remove_npc(id)убрать NPC, вернёт true/false
pacmine.player_pos(name)таблица {x=, y=, z=} или nil, если игрока нет онлайн

Примеры

Приветствие при входе

pacmine.on("join", function(name, premium)
    pacmine.log("Welcome, " .. name .. (premium and " *" or ""))
end)

NPC-страж на спавне, который патрулирует и здоровается

local bot = nil
local CX, CZ = 56.5, 56.5

pacmine.on("tick", function(sec)
    if bot == nil then
        local y = pacmine.surface_y(CX, CZ)
        bot = pacmine.spawn_npc("PacBot", CX, y, CZ)
    else
        local a = sec * 0.5
        local x = CX + math.cos(a) * 5
        local z = CZ + math.sin(a) * 5
        pacmine.move_npc(bot, x, pacmine.surface_y(x, z), z, math.deg(a) + 90)
    end
end)

pacmine.on("join", function(name)
    pacmine.say("PacBot", "Добро пожаловать, " .. name .. "!")
end)

Чат-бот, отвечающий на ключевое слово

pacmine.on("chat", function(name, text)
    if text == "hello" then
        pacmine.say("Parrot", "hello " .. name .. "!")
    end
end)
