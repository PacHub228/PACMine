Что такое PACMine

Небольшая воксельная песочница на Java с LWJGL (OpenGL + GLFW): генерация мира с пещерами и рудой, добыча и крафт, печки и плавка, зомби и животные, вода и лава с настоящей физикой растекания, мультиплеер и достижения.

С чего начать

Просто поиграть

  1. Скачай PACMine-Launcher.jar со страницы релизов
  2. java -jar PACMine-Launcher.jar
  3. Лаунчер сам скачает и соберёт игру

Поднять свой сервер

  1. Скачай PACMine-Server.jar
  2. Положи в пустую папку, запусти
  3. Подробности — на странице сервера

Формат сохранений

Миры хранятся в собственном шифрованном формате .pms (PAC Mine Saves) — блоки, инвентарь, зомби, животные, дроп, печки, время суток. Достижения — в .pma. Оба формата зашифрованы (PMCrypt), чтобы сейвы нельзя было небрежно поправить в текстовом редакторе.
